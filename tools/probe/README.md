# 设备探针 VoxPalm Probe

实测一台设备（遥控器、无线麦、翻页笔、脚踏板……）在 Mac 上到底能被读到什么：每个键发出什么事件、有没有「松开」、单击 / 双击 / 长按哪些被固件占用、蓝牙收音的实际采样率。结果导出成 JSON 和 Markdown 报告。

探针只监听、不拦截：运行时设备照常工作，不装驱动，不改任何系统设置。

`watch` 和 `wizard` 会暂时把探针登记为「正在播放」，测试期间其他播放器可能收不到媒体键；退出监听后会撤销登记。`list` 不会登记。

## 编译

需要 macOS 14 以上和 Xcode（或 Command Line Tools）。

```bash
cd tools/probe
swift build -c release
```

编译好的程序在 `.build/release/voxpalm-probe`。

## 权限

探针在哪个终端 App 里运行，权限就授给哪个 App（比如「终端」）。第一次运行 `permissions` 会弹系统授权框：

```bash
.build/release/voxpalm-probe permissions
```

- **输入监控**：读遥控器、键盘类设备的按键和系统媒体键都要它。系统设置 → 隐私与安全性 → 输入监控 → 打开终端 App 的开关，然后完全退出终端再打开。
- **麦克风**：只有实测采样率时用。录音只在本机分析，不保存、不上传。

## 用法

| 命令 | 做什么 |
|---|---|
| `list` | 列出外接 HID 设备和收音设备，检查权限；`--all` 连内置键盘、触控板一起列 |
| `audio --measure <序号或名称>` | 从这个收音设备真的录 5 秒（`--seconds` 可改），量实际采样率、音量和有效频宽 |
| `watch` | 实时打印所有通道的事件，按回车结束；`--hid 1,2` 只看某几台，`--raw` 显示原始报告，`--out 目录` 存成 JSON |
| `wizard` | 手势向导，生成完整报告（推荐） |

`--seconds` 必须大于 0：`audio` 测量最长 60 秒，避免长期录音占用大量内存；`watch` 最长 86,400 秒。报告写入失败时命令返回失败状态，便于脚本识别。

### 手势向导

```bash
.build/release/voxpalm-probe wizard
```

按提示依次填设备名称、选要记录的 HID 设备、选要实测的收音设备、可选做连接测试，然后给每个键起个名字，逐个做：

1. 单击
2. 双击
3. 长按 1 秒
4. 长按 3 秒

每一步按回车开始，停手 2 秒（长按时更久）后自动结束。每步结束后会问设备自己有没有反应（指示灯变了、切模式、关机、进配对）——有的话简单写一句，这个手势会标成「被固件占用」。已经知道会让设备关机或切模式的手势，可以输入 `s` 跳过并写上原因。

测试的那几秒里别碰键盘：系统键盘事件看不出来自哪台设备，会混进报告。

报告默认写到当前目录的 `probe-reports/<时间>-<设备名>/`，里面有 `report.json` 和 `report.md`。蓝牙地址默认只留前 3 段（厂商段），要完整地址加 `--no-redact`。

## 记录了哪些通道

| 通道 | 来源 | 能看出来自哪台设备 | 说明 |
|---|---|---|---|
| HID | IOHIDManager，不独占 | 能 | 按用途解析后的值，按键类的值区分按下 / 松开，带设备时间戳 |
| HID 原始 | 同上 | 能 | 原始输入报告（十六进制），厂商自定义的数据看这里 |
| 媒体键 | 事件监听（只听不拦），NX_SYSDEFINED | 不能 | 播放 / 暂停、音量等系统媒体键，区分按下 / 松开 / 连发 |
| 键盘 | 事件监听（只听不拦） | 不能 | 系统收到的按键（遥控器上的方向键、回车常常走这里） |
| 正在播放 | MPRemoteCommandCenter | 不能 | 蓝牙耳机、遥控器的 AVRCP 播放控制；探针运行时会把自己登记成「正在播放」，所以别的播放器暂时收不到媒体键 |
| 音频 | CoreAudio | 能 | 设备音量、静音、采样率、系统默认输入输出的变化；有的蓝牙耳麦按键只表现为音量变化 |
| 设备 | IOHIDManager、CoreAudio | 能 | 设备连上 / 断开（长按切模式、关机会表现为断开） |

## 报告怎么读

结论表里每格的符号：

| 符号 | 意思 |
|---|---|
| ✅ | 能读到按下和松开，App 可以自己识别单击、双击、长按 |
| ⚡ | 只有一次性触发、没有松开：只能当「按一下」用，做不了按住说话 |
| ⏱ | 能读到按住时长 |
| 🔁 | 按住时自动连发，可以用连发推算按住时长 |
| 🔀 | 固件自己识别了这个手势，发出了和单击不同的键 |
| ⛔ | 被固件占用：设备有自己的反应或断开了，不能拿来映射 |
| ❓ | 单击有事件、这个手势却什么都没有，疑似被固件占用 |
| ✖️ | 没有事件 |
