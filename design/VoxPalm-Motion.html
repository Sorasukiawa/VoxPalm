掌声 VoxPalm UI 第二版 · 动效与交互 · 已定稿

一个东西从头跟到尾，
不是一页页静态表单。

这一版在上一版（你说「比上版好多了」的卡片、彩色图标块、珊瑚色按钮）上只改两件事：东西怎么动和从哪儿跳到哪儿。核心做法是让同一个物件贯穿始终——你选的那台设备的示意图，从引导的转盘、到说话键那一步、到设置的按键页、再到面板的磁贴，一直是同一张图；按住说话的那颗 从菜单栏、浮窗到面板也是同一颗。下面三块桌面都能点，空格可以当成「按住遥控器的键」。

设备按一下实物，自动认出来选设备那步不用在下拉框里找名字：拿起遥控器随便按一个键，转盘自己转到它，整台设备亮一圈。
说话键图上亮着的键就是建议示意图上点亮推荐的键（遥控器是确认键），按一下实物就对上；想换就点图上别的键。
浮窗先出 ，满了才展开按下先冒出一颗 ，外圈一圈走完（长按时间）才展开成声波；短按就地摇一下消失，不再闪一个大胶囊。
收尾引导结束，窗口收进菜单栏点完成，窗口缩小飞进菜单栏的掌声图标，图标亮一圈并冒出提示：以后在这儿找我。

01 · 日常使用

菜单栏图标 → 面板 → 说话浮窗 → 设置

按住空格（或下面的珊瑚色按钮）= 按住遥控器的确认键：浮窗先冒出 ，外圈走满 0.5 秒才展开成声波，松手后声波收成三行字、贴进备忘录，再缩回 掉下去。点菜单栏的掌声图标打开面板，面板里的两块磁贴点一下就地展开、直接换设备；右键图标是快捷菜单，按住 ⌥ 点图标直接暂停。

演示控制
面板：上面一块「怎么说话」平时写「━ 长按 [确认键] 说话」；按住时这一块就地变成声波 + 计时，转写时变成闪动的字行，出完字新的一条从上面滑进「最近」。不用另开窗口就知道发生了什么。借鉴：Raycast 的结果就地刷新
面板：两块磁贴，点开就地换「控制」和「收音」做成两块磁贴（像控制中心的模块）。点控制磁贴，面板长高，横排出现设备示意图的小图，点一下就换；点收音磁贴，展开麦克风列表，选中的那个在跳音量。借鉴：控制中心、Bartender / Ice 的菜单栏下拉
出问题时：一条提醒条，一步到位缺权限时图标右下角出黄点，面板顶上滑出提醒条；点「开启」直接打开系统设置和拖拽小窗，不先绕去设置窗口。设备没连上时提醒条写「去蓝牙设置」。借鉴：Codex / Claude 桌面版的授权
02 · 第一次打开

6 步，每步只做一件事，做完自己往下走

欢迎 → 权限 → 用什么按 → 用什么收音 → 说话键 → 其余的键。每一步进来时元素依次浮上来（40 毫秒一个），换步是整页往左滑、新的一页从右边弹进来；返回就反过来。能自动判断的不让你点：权限打开了自动下一项，按了实物自动认设备。最后一步点完成，窗口收进菜单栏。点下面的卡片可以直接跳到那一步。

03 · 选设备细看

左边转盘画出设备，右边列表按类别分组，两边是同一份数据

照你的想法做的：左边直接把设备画出来，左右滑动切换，底下写名字和连接状态；右边是按类别分组的列表，点哪一行转盘就转到哪台。转到哪台就是选了哪台，「继续」按钮上直接写着它的名字，不会选错。

拖、滑、点、按方向键都行转盘可以用鼠标拖（带惯性，拖过头会被弹回来）、触控板左右滑、点两边露出来的半台设备、或者按 ← →。名字跟着往同一个方向滑出、滑入，底下的小点变长表示位置。
按一下实物，自动认出来这一步一直在听所有设备：按遥控器、翻页笔、媒体键上的任意键，转盘自己转到那台，外圈亮两下，顶上冒出「认出来了」。普通键盘打字不算，免得边打字边乱转。要改引擎：引导时同时听所有来源（现在只听选中的那台）
新连上的设备会自己滑进来在这一步时去系统设置连上蓝牙遥控器，列表里那一行从灰变亮、带一个「新」字，转盘直接转过去。所以不需要「刷新」按钮。
没连上的也列出来，但是灰的认识的型号（小米蓝牙遥控器 2、Siri Remote 等）即使没连上也列在对应类别里，灰色，转到它时写「没连上 · 怎么连」，「继续」变成「先连上它」。这样新用户知道还支持什么。
为什么按类别分组，不按品牌通用设备（翻页笔、脚踏板、键盘媒体键、耳机按键）没有品牌可分；开源版也不画厂商标志。所以按「遥控器 / 翻页笔和脚踏板 / 无线麦 / 键盘 / 耳机」分组，品牌写在每一行的小字里。官方版在「无线麦」组里多出具体型号。
收音那一步照同样的样子左边画麦克风（笔记本、USB 接收器、耳机、iPhone），对着它说话，外面一圈圈的光跟着音量跳；右边按「这台 Mac / 外接 / 蓝牙 / iPhone」分组。蓝牙耳机写清「16 kHz 通话音质，转写会差一些」。控制设备本身就是无线麦时，顶上提示「收音也用它？」。
04 · 说话浮窗

先出来，满了才展开；出完字再缩回

浮窗还是屏幕下方正中的深色胶囊，不抢焦点、不挡鼠标。变的是它怎么出现和怎么变：顺序照 Logo 的三段走—— 按下 → 声波在听 → 字行出字。点下面的状态可以单独看。

0 – 0.5 秒按下：只有 从底下弹出一颗 44 点的圆， 一跳一跳，外圈一圈珊瑚色按长按时间走满。这时已经在录（防吞字），只是还没算数。
0.5 秒起满了：展开成胶囊宽度用弹簧拉开，声波跟着音量跳，计时数字滚动；副标题只写设备名「小米遥控器 2」；收音是蓝牙通话音质时才多一句提醒。
松手声波收成字行七根竖条压扁、变成三行字，一行接一行从左往右闪着填满， 变薰衣草色。
出字后 1.8 秒写清贴到了哪「已输入 23 字 · 备忘录」，下面一行是开头几个字。然后胶囊缩回 ，往下掉着淡出。
短按就地摇一下没满 0.5 秒就松手： 变灰、整颗左右摇一下，旁边一行「按住超过 0.5 秒才算」，1.2 秒后消失。只在没绑单击的键上提示。
出错留 4 秒，写怎么办贴不进去：黄点，「字在剪贴板里，按 ⌘V」；没声音：灰点，「没听到声音，看看麦克风」；其他错误红点。浮窗不能点，所以同时给菜单栏图标挂个黄点，面板里有提醒条。
05 · 菜单栏图标

六个状态不变，改成平滑过渡

状态和上一版一样（录音时 用珊瑚色，平时是黑白模板图），新加两处：准备中时 外面多一圈走满的进度，和浮窗同步；出完字两行字从左往右刷一下再回到待命。状态之间用弹簧过渡，不是直接换图。

06 · 设置窗口

左边栏 6 页，设备和按键页直接用示意图操作

侧边栏是浮起来的一块（macOS 26 的样式），选中的底色用弹簧滑过去；换页时旧页淡出、新页往上浮 8 点。设备页和引导里的转盘是同一个东西；按键页在示意图两边拉引线写每个键做什么，点键或点标签就在旁边弹出编辑小窗，按实物上的键图上对应的键会闪。

演示控制
设备顶上「控制设备 | 收音设备」切换，下面就是引导里那个转盘 + 分组列表。免费版同时用 1 台；Pro 每一行右边多一个开关，可以几台一起开。
按键「图 | 表」两种看法，切换时交叉淡入。图：引线只拉给设了动作的键，引线是画出来的（从键到标签一笔划过去）。表：行是键、列是单击 / 双击 / 长按，读不到松开的设备长按那一列画斜线。编辑小窗里手势用分段控件，动作按「说话 / AI 编程 / 通用」分组。
语音出字方式做成两张带小动画的卡：内置转写（ → 芯片 → 字）和外部输入法（ → 输入法 → 字），选中的那张虚线开始流动。防吞字的时间线拖滑块时，珊瑚色那段跟着伸缩。
权限和引导里同一组卡片，缺的那张高亮、带拖拽演示；全开了收成一行「3 个权限都开了」。侧边栏「权限」后面挂黄色数字角标。
Pro每个功能一张卡，卡上有一段几秒的小循环动画说明它干什么（多台设备轮流亮、按 App 换键位……）。不写价格，写「1.0 正式版发布时开卖」。
关于大 Logo 也能按住（和欢迎页一样会动），版本、许可一行，「重新打开引导」「导入 / 导出设置」。

11 · 写代码时

落到 SwiftUI 的做法，和要动引擎的地方

界面
  • 转盘：ScrollView(.horizontal) + .scrollTargetBehavior(.viewAligned) + .scrollPosition(id:)，两边缩小变淡用 .scrollTransition（macOS 14 起就有）。列表和转盘绑同一个 selectedID。
  • 列表选中底色、侧边栏选中、分段控件：matchedGeometryEffect 让底色滑过去。
  • 换步、换页：.transition(.asymmetric(...)) + 子元素按序号加 .delay(0.04 × i)。
  • 浮窗：还是固定画布的 NSPanel； 的进度圈是 Circle().trim 按长按时间线性走；摇一下用 KeyframeAnimator；计时用 .contentTransition(.numericText())。
  • 窗口收进菜单栏：AppKit 里拿状态栏按钮所在窗口的位置，NSAnimationContext 把引导窗口的 frame 缩到图标那儿、同时降透明度，然后 orderOut；提示气泡用挂在状态栏按钮上的 NSPopover。
  • 面板长高：NSHostingController.sizingOptions = .preferredContentSize，NSPopover 自己会带动画改大小。
  • 引线：示意图已经按毫米描述，引线在 Canvas 里画，用 .trim(from:to:) 做「一笔划出来」。
  • 减少动态效果：读 accessibilityReduceMotion，弹簧全部换成 .easeInOut(duration: 0.12)，转盘不缩放只淡入淡出。
引擎和数据（不只是界面）
  • 引导时同时听所有设备：按一下就认出是哪台。现在学键只听选中的设备，要加一个「全部来源」的监听，只在引导的设备那步打开；普通键盘字母键不算。
  • 认识但没连上的型号：要一张「已知型号」表（示意图 id、类别、配对说明），没连上的也能列出来。
  • 设备连上断开实时更新：HID 和音频设备的插拔通知接到列表上，新设备带「新」标记。
  • 推荐的说话键：每种示意图标一个推荐键（遥控器确认键、翻页笔黑屏键、无线麦正面键、脚踏板中踏板），引导里点亮它。
  • 说话键那步的「试写区」：引导窗口里放一个真的输入框，字直接贴进去，顺便验证辅助功能权限和贴字链路是通的。
  • 面板「最近」：记最近 3 条（文字、贴到哪个 App、时间），只存在内存里，退出就清。
  • 浮窗显示开头几个字：转写结果的前 16 个字，只在本机屏幕上显示。
