2026-10-19 本人试用后说引导做得不错、App 内的界面还差，照引导的做法把 App 内整体精修了一遍（没换配色和版式）：

- 设置窗口：左边栏改成自己画的浮起来的一块（macOS 26 用玻璃效果），选中底色用弹簧滑过去，「权限」缺几个挂几的橙色角标，最下面是监听状态和开关，⌘1–⌘6 和上下键换页；标题栏加高，左上角三个按钮落在边栏里。右边整页透珊瑚色的光，每页是大标题加一句说明，下面一张张圆角卡片（彩色图标块 + 标题 + 一句说明），不再用系统的分组表单；换页时旧页淡出、新页往上浮，卡片依次浮上来。
- 各页：设备页的「控制 / 收音」和按键页的「图 / 表」换成同一种滑动分段；按键页设备卡片带设备小图和外形选择，「AI 编程」预设单独一张卡，手势时间尺拖滑块时线和字一起弹过去；语音页每一项是卡片里的一行（名字 + 小字说明 + 右边控件），外部输入法的流程画成带图标的几步；权限全开了收成一张「3 个权限都开了」；Pro 页每行两张卡一样高；关于页加了导出 / 导入设置（从按键页挪过来）。
- 面板：说话块左边是一颗照 Logo 画的 ●（带厚度，按住就能试说话），准备中外圈走满、正在听一圈圈扩散、转写中变薰衣草色、出完字打勾、暂停时是空心的；右边文字就地换。面板左上角也透珊瑚色的光，每次打开里面几块依次浮上来。
- 右键菜单每项前面加了图标，第一行写现在的状态；提示气泡加了图标（引导结束那句带会动的 Logo）。编辑小窗的「完成」改成珊瑚色按钮，「清除这一格」改成灰色带垃圾桶图标。

和设计稿不一样的地方：

- 按键页的引线和标注沿用原来的画法，改了动作的标注会闪一下。
- 编辑小窗已照设计稿改成「单击 / 双击 / 长按」分段 + 分组的动作按钮（2026-10-19），表格里点格子弹的也是它。小差别：用系统的弹出框，带小箭头；「按住说话」只能设在长按上；「开始 / 结束说话」也能勾「说完自动按回车发送」，快捷键这些通用动作设好后也能勾「做完直接开始说话」（原来就有）；「说完自动按回车发送」要先勾「做完直接开始说话」才能勾；带「…」的动作再点一下不会清掉这一格，只有不用再填东西的才会。
- 转盘用触控板左右滑时一次走一格，不跟手；鼠标拖动是跟手的。
- 按实物认设备只听 HID 设备和系统媒体键：键盘按键（免得打字时乱认）、「正在播放」和闭源适配的设备要先在列表里选中。

## 方向

- 掌声大部分时间只是菜单栏里的一个图标，界面跟随 macOS 原生样式（左边栏设置窗口、分组表单、系统字体）。
- 品牌只用在三处：珊瑚色强调、菜单栏图标的状态、说话浮窗。
- 核心想法：Logo 从左到右的三段「● 按钮 → 声波 → 文字行」，正好对应说话的三个状态「按下 → 正在听 → 出字」。菜单栏图标和说话浮窗都按这个顺序变化。手机、手表上的说话键也是这颗 ●，连按钮的厚度一起照搬。

## 颜色和字体

| 名字 | 色值 | 用在哪 |
|---|---|---|
| 珊瑚 | `#FF8A5C → #D85A30` | 强调色、● 按钮、声波 |
| 珊瑚深 | `#A93F1C` | 按钮下方的厚度 |
| 珊瑚文字 | 浅色 `#BF4B24`，深色 `#FF9670` | 小字，保证对比度 |
| 墨 | `#2B2840 → #17151F` | 浮窗底色、图标底 |
| 奶油 | `#FFF3EA` | 深色底上的文字行 |
| 薰衣草 | 浅色 `#6259A6`，深色 `#A9A2E2` | 转写中 |

App 界面用系统字体（SF、苹方），不打包思源黑体；计时、采样率、秒数用等宽数字。圆角：窗口 16，分组 10，按钮 7，浮窗全圆。

## 写代码时的要点

- 说话浮窗用不抢焦点的 `NSPanel`（`.nonactivatingPanel`、`ignoresMouseEvents = true`、能出现在所有桌面和全屏 App 上），否则光标会从正在打字的 App 里跑掉。
- 设置窗口原来用 `NavigationSplitView` + `Form(.grouped)`；2026-10-19 起换成自己画的浮起边栏 + 卡片（`SettingsCard`、`SettingRow`），按键表用 `Grid`。
- 现在用 SwiftPM 打包、没有 asset catalog，系统级的强调色设不了；先在界面上用 `.tint()` 统一成珊瑚色。
- 两处新行为要改引擎，不只是界面：浮窗要知道字贴到了哪个 App（前台 App 名）；字贴不进去时（比如缺辅助功能权限）先放进剪贴板再提示。

## 已定（2026-10-19 本人确认）

- 整体方向：原生样式 + 三处品牌（珊瑚色强调、菜单栏图标状态、说话浮窗），不做整套墨色皮肤。
- 浮窗位置：屏幕下方正中，不跟光标。
- 录音时菜单栏的 ● 用珊瑚色；平时是黑白模板图。
- 按键页在设计稿的按键表上面加设备示意图（照产品图画的矢量线稿，引线标注每个键），点图上的键，表格里对应的行高亮。
