# 手机配对界面

当前源码提供 Mac 配对页、iPhone/iPad 配对客户端、连接测试和手机按住说话到 Mac 内置转写。通用系统按键、鼠标触控板尚未接入。没有发布手机版安装包，真实手机扫码、同网发现、钥匙串及手机收音仍需真机验收。

## 使用流程

1. Mac 的设置 → 手机，打开「允许手机连接和语音输入」，点击「配对新手机」。
2. 手机打开掌声，点击「扫描 Mac 上的二维码」。相机仅用于读取二维码，不录音或保存画面。也可以展开 Mac 的一次性长码，在手机手动粘贴。
3. 配对码五分钟有效、仅用一次。关闭配对页会取消邀请；失败后请生成新的邀请。二维码和长码都包含本次配对秘密，请勿分享。
4. 配对后在手机点击「连接」，再点击「发送连接测试」。Mac 的手机页显示收到的次数。测试消息不触发其他 App 的按键或麦克风。
5. 需要停止时，Mac 关闭连接开关，或手机点击断开。手机离开前台会断开，回来后手动重连。Mac 每次启动默认关闭手机连接。
6. 任一端可移除本地配对；对端的列表不会自动删除，可在对端再清理。删除失败会保留待清理记录，点击重试。配对在断线瞬间可能只在一端完成，这时两端移除后重新配对。

## 按住说话

在手机主动启用麦克风授权，并在 Mac 设置 → 语音中选择内置转写、准备好本机模型。连接后按住说话，Mac 接受这轮请求才开启手机的内置麦克风。松开会先送完尾块，再由 Mac 转写；手机显示正在录音、转写及完成或失败状态。Mac 正在处理另一轮语音或暂停监听时不会接收新一轮。

声音使用 16 kHz 单声道 S16LE，每块最多 40 ms，只经已配对的加密通道送到 Mac。手机交付队列最多 64 KiB，网络另有积压上限；Mac 的声音缓冲、录音与转写时间受已有语音预算约束。声音仅放内存，不保存文件或上传云端。转写文本不回传手机，Mac 仍检查按下时的输入目标；密码框、目标改变等情况按原有投递规则处理，不自动按回车。

移出说话按钮、点击取消、切到后台、输入设备改变、中断或达到五分钟上限都取消这一轮。语音结束后在手机取消，会断开连接以取消 Mac 尚未完成的转写；回来需要手动重连。Mac 撤销设备、关闭手机连接、暂停监听、睡眠或切换用户会取消尚未完成的手机语音。已经完成的贴字无法撤回。VoiceOver 可双击开始、再次双击结束。

两端需在同一网络。未找到设备或网络不可用时，界面提示检查网络与系统设置 → 隐私与安全性 → 本地网络；不把所有网络错误一律宣称成拒绝授权。手机扫码需相机授权，拒绝后可改用长码。[Apple 本地网络隐私说明](https://developer.apple.com/documentation/technotes/tn3179-understanding-local-network-privacy)

## 数据与连接

独立 `phone-devices.json` 保存随机本机标识、配对标识、双方随机标识、时间及状态，不保存设备真实名称、地址或密钥。手机长期密钥使用非同步、本机解锁后可访问的数据保护 Keychain 条目。Mac 当前独立打包不含数据保护钥匙串要求的 provisioning profile，因此显式使用系统本地登录钥匙串，默认访问列表仅信任创建条目的 App，不放宽访问权限、不在失败后自动更换存储。不使用明文文件保存密钥。Mac 的锁定行为由登录钥匙串设置决定，不能把手机的 `WhenUnlockedThisDeviceOnly` 语义套用到它上面。目录损坏时拒绝覆盖；旧快照不能覆盖别的进程新写的记录。

实现选择依据：[Apple 的两种 Mac 钥匙串说明](https://developer.apple.com/documentation/technotes/tn3137-on-mac-keychains)、[默认钥匙串访问控制](https://developer.apple.com/forums/thread/115425)。Apple 推荐新的数据保护实现；后续 Mac 配置受支持的签名/profile 后再设计显式迁移，当前不隐式双读或复制密钥。

写密钥前先持久化待完成记录，握手结束后才激活；未完成的记录不能连接。撤销先停止当前通道、持久化禁止连接状态，再删除密钥。磁盘不可写时仍立即停止当前通道，但不能声称撤销已持久保存，需修复存储后重试。相机、网络和配对码不写日志；配对码只有主动展开时才显示长文本。

加密仍采用 [局域网连接文档](手机局域网连接.md) 描述的 TLS 1.2 PSK AES-GCM；不提供前向保密。

## 构建与验证

- Mac 入口依旧为 `App/Package.swift`，构建方式不变。
- 手机工程为 `Mobile/VoxPalmMobile.xcodeproj`，scheme `VoxPalmMobile`，最低 iOS 16，iPhone 与 iPad 共用当前原生列表界面。真机安装需另行配置开发签名；仓库不带团队、证书或描述文件。
- `bash scripts/check.sh` 包含共享包/应用测试和手机模拟器目标编译。测试使用临时设备目录、内存凭据和回环 TLS；不访问本人钥匙串或真实控制设备。
- 模拟器编译不等于真实手机扫码、收音或局域网验收。手机工程声明相机、麦克风和本地网络用途，不申请后台音频权限。合成 PCM 的回环测试与假转写/假贴字只证明代码链路，不证明真实识别效果。
