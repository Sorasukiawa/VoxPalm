# 外部输入法配置与验证状态

更新：2026-10-25。以下结果来自 macOS 27.0.1 的本机测试，不代表所有系统版本或输入工具版本都已兼容。

掌声通过模拟输入工具的语音快捷键工作，不直接调用这些工具的识别接口。设置 › 语音选择「外部输入法」后，语音键和按法都要与对应工具的设置一致。

| 输入工具 | 本轮验证结果 | 配置要点 |
| --- | --- | --- |
| 微信输入法 3.0.0 | Fn 按住、右 Option 开始／结束均实际输入中文；切麦和恢复通过 | Fn 按住需先启用；输入法自己的麦克风选「自动检测」 |
| 豆包输入法 1.0.2 | Fn 按住、左 Option 开始／结束均实际输入中文；切麦和恢复通过 | 测试时选中了豆包输入法；未验收跨输入法的全局唤起；麦克风选「自动检测」 |
| macOS 系统听写 | 自定义组合键启动、结束及英文出字通过；模拟双击 Fn 未能启动 | 本机对照使用 Control + Shift + D；测试时在系统听写中明确选择收音设备；普通话出字尚未通过 |
| Handy 0.9.8 | 待完成真实出字验收 | 设置「自定义快捷键」，录制与 Handy 一致的组合键；切换模式使用「按一下开始、再按一下结束」 |
| Typeless | 待验证 | 需先完成输入工具自身的登录、权限和语音配置 |

## 选择麦克风

微信、豆包可以在自己的设置里单独固定收音设备。固定选择某支麦时，掌声临时切换系统默认输入不会改变那个选择；选择「自动检测」后，本轮已验证它们能跟随切换。

因此，不能把“只录到 Mac 自带麦”当成微信输入法本身不支持切麦。掌声的提示只提醒检查输入法设置，并不读取或保证输入法当前实际使用的麦克风。

系统听写也有自己的收音设备选项。本轮英文出字是在明确选定测试声卡后通过的，尚未证明其「自动」选项会始终跟随掌声切麦。

## 组合快捷键

在「输入法的语音键」里选择「自定义快捷键」，再点「录制」或「重录」并按下组合键。组合键不能持续按住；尚未录制或使用不支持的按法时，掌声会提示错误，不报告已经交给输入法。

## 本轮验证的范围

使用当前语音会话核心的真实按键桥接、真实输入工具和独立的原生输入框；固定语音样本经本机音频回环输入，再观察最终文字、输入工具的录音日志和系统默认麦克风恢复。这里的出字结果不是假的识别回调。

本轮不包含真人遥控器到输入法的完整链路、无线麦声学质量、长时间连续使用、自动回车发送、其他 App 的输入框，以及切麦期间手动更换系统收音设备的验收。
