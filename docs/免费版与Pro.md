# 免费版和 Pro

原则：免费版是「一个人、一套设备，把『按键 → 说话 → 出字』完整跑通」，不限时间、不限次数；Pro 是「多设备、多场景、专业工作流」。支持的设备不分版本，免费版也能用全部设备。

| 功能 | 免费 | Pro |
|---|---|---|
| 全部支持的设备（DJI 无线麦、小米遥控器、Siri Remote、翻页笔、脚踏板等） | ✅ | ✅ |
| 1 个控制设备 + 1 个收音设备，可以分开选 | ✅ | ✅ |
| 多个控制设备同时在线（比如遥控器 + 脚踏板 + 无线麦一起用） | — | ✅ |
| 每个键的单击、双击、长按 → 快捷键、文字片段、媒体控制、打开 App | ✅ | ✅ |
| 1 套全局键位方案 | ✅ | ✅ |
| 多套键位方案，按当前使用的 App 自动切换 | — | ✅ |
| 按住说话 / 按一下开始、再按结束 | ✅ | ✅ |
| 接豆包、微信、Typeless、Handy 等输入工具 | ✅ | ✅ |
| 内置本地转写（系统自带转写 + whisper.cpp） | ✅ | ✅ |
| 自动切换麦克风、预录缓冲（防止吞掉第一个字） | ✅ | ✅ |
| 转写增强：热词和自定义词表、口语润色、按 App 换转写方式 | — | ✅ |
| 录音剪辑软件动作包：Logic Pro、Final Cut Pro、Premiere Pro、DaVinci Resolve、Audition、Reaper、Audacity | — | ✅ |
| 组合动作（一个键依次执行多步） | — | ✅ |
| 配置导入导出 | ✅ | ✅ |
| 多台 Mac 同步配置（以后再做） | — | ✅ |
| 设备探针、提交兼容报告 | ✅ | ✅ |

## 怎么买

- Pro 是一次买断，不自动续费；价格在 1.0 正式版发布时公布。
- Pro 在 Mac 上购买。连到这台 Mac 的 iPhone、iPad、Apple Watch 共用 Mac 的 Pro，不用另买；掌声遥控 App 本身免费，App 里不卖东西。
